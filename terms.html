2. DESCRIPTION OF SERVICE

QVIEW Player is a media player application for Android TV that allows users to:

  • Add and manage M3U/M3U8 playlists
  • Connect to Xtream Codes API providers
  • View Electronic Program Guide (EPG) data
  • Search for programs within EPG
  • Access catch-up archives (if supported by provider)
  • Auto Frame Rate (AFR) support for smooth video playback
  • Advanced network buffering configuration for stable streaming
  • Secure synchronization of settings and favorites between devices
  • Organize channels and favorites
  • Use parental control features

The App does NOT provide any content. Users must obtain media playlists and subscriptions from third-party providers.
